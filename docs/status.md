# 项目状态与支持范围

[文档首页](README.md) / 项目状态

当前源码版本：**0.1.0-SNAPSHOT，开发版**。本页说明能力与支持边界，不对未来发布日期或生产容量作承诺。

## 已有能力与依赖

| 场景 | 当前状态 |
| --- | --- |
| 独立平台启动 | 公共Maven/npm依赖、本地账号、MySQL/Redis、单JAR前端 |
| HTTP API配置与调用 | 工作区、发布、授权、Token、治理；真实订单HTTP链路已验 |
| Dubbo接入 | 已有SDK、受控连接与泛化调用实现；生产注册中心需单独验证 |
| 文档与门户 | 发布文档、租户范围、公开示例、在线调试与导出 |
| 本地身份 | 配置账号、服务端会话、CSRF；没有自助注册/找回密码/账号管理UI |
| 外部身份 | SPI与替换装配已提供；不随开源仓库附带公司专有实现 |
| 签名、MCP与跨环境 | 平台侧实现存在，需要各自密钥、网关或目标环境配置 |
| Docker | Compose提供数据库/Redis；没有发布应用镜像 |
| SDK分发 | 源码与本地install；当前没有公共Maven正式制品 |
| CI | 提供GitHub Actions工作流；工作流文件不等于远程执行已通过 |

## 验证范围

- macOS、JDK25、独立MySQL8.4/Redis、本机Chrome上的后台/门户、账号与示例HTTP调用已有实际结果。
- 默认单元/H2 HTTP回归、前端测试和公共依赖构建已有记录，详见 [验证证据](verification.md)。示例Provider可执行打包问题已修正并按真实启动复验。
- Windows/WSL、Linux生产部署、Compose容器实跑、外部Nacos、跨网络Dubbo、外部MCP网关、多实例会话/高可用和压力容量尚未完成本轮验收。
- 文档提供对应部署要求与扩展入口；未验不代表一定不可用，也不能标为已支持生产。

## 接下来可贡献的方向

1. 各操作系统的可复现启动和容器验收，补充实际版本/命令。
2. 标准身份协议适配和更完整的账号管理体验。
3. 多实例会话、备份恢复、容量及故障注入验证。
4. SDK兼容矩阵、正式制品与版本升级流程。
5. 教程、错误提示、无障碍和更多真实接入示例。

这些是开放讨论的方向，不是已经实现的功能或已承诺日期。需要新功能时请先提交 [功能建议](https://github.com/ChenYilei2016/cyl-openplatform/issues/new?template=feature_request.yml)。
